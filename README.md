## Mục đích dự án
Dự án FUNiX Passport được phát triển nhằm hỗ trợ việc quản lý và tự động hóa phụ đề (subtitle) cho các nền tảng học trực tuyến như Udemy, YouTube, và các trang web giáo dục khác.

## Cấu trúc nhánh (Branches)
Dự án hiện có **9 nhánh** bao gồm:

| Nhánh | Mô tả |
|-------|-------|
| `master` | Nhánh chính của dự án |
| `backend` | Nhánh phát triển phần backend |
| `document` | Nhánh chứa tài liệu |
| `feat/auto_enable_subtitle` | Tính năng tự động bật phụ đề |
| `bug/clear_console_log` | Sửa lỗi xóa console log |
| `bug/applieddigitalskills` | Sửa lỗi trên trang Applied Digital Skills |
| `bug/onpage_on_sololearn` | Sửa lỗi trên trang SoloLearn |
| `subtitle-by-time` | Tính năng phụ đề theo thời gian |
| `youtube-subtitle` | Tính năng phụ đề cho YouTube |
