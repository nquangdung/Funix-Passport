## Mục đích của Repository

Repository này được tạo để thực hiện **Assignment 02** của môn **SWE102x - Software Engineering** tại FUNiX.

Nội dung của repository nhằm thực hành các thao tác quản lý mã nguồn với Git như:

- Tạo và quản lý Branch
- Commit mã nguồn
- Merge Branch
- Giải quyết xung đột (Merge Conflict)
- Revert Commit
- Push và Pull Repository
- Làm việc với Remote Repository

## Cấu trúc các Branch

#### master
- `Branch chính của dự án, chứa phiên bản ổn định sau khi đã hoàn thành và kiểm thử.`

#### feat/auto_enable_subtitle
- `Phát triển tính năng tự động bật phụ đề khi video được tải.`

#### bug/clear_console_log
- Loại bỏ các câu lệnh `console.log` không cần thiết nhằm làm sạch mã nguồn.

#### documentation
- `Cập nhật và bổ sung tài liệu cho dự án.`
#### backend

- Bổ sung tài liệu mô tả thiết kế Backend dự kiến của hệ thống FUNiX Passport.
