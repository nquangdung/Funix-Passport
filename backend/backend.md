# Backend của FUNiX Passport

## 1. Vai trò của Backend
Backend có vai trò cung cấp dữ liệu và hỗ trợ các chức năng cần thiết cho extension FUNiX Passport, đặc biệt là dữ liệu phụ đề và các thông tin cấu hình liên quan.

## 2. Mục đích xây dựng
- Cung cấp dữ liệu phụ đề cho extension
- Hỗ trợ quản lý dữ liệu liên quan đến video học tập
- Tạo nền tảng để mở rộng hệ thống trong tương lai

## 3. Các vai trò sử dụng Backend

### Học viên
- Nhận dữ liệu phụ đề
- Sử dụng các chức năng hỗ trợ học tập

### Quản trị viên / Nhà phát triển
- Quản lý dữ liệu phụ đề
- Kiểm tra, bảo trì và nâng cấp hệ thống
- Quản lý các chức năng hỗ trợ extension

## 4. Các chức năng chính của Backend
- Cung cấp dữ liệu phụ đề theo video hoặc khóa học
- Lưu trữ và quản lý dữ liệu phụ đề
- Hỗ trợ cấu hình cho extension
- Hỗ trợ mở rộng thêm các chức năng khác trong tương lai

## 5. Kết luận
Backend là thành phần hỗ trợ quan trọng giúp extension hoạt động ổn định, cung cấp dữ liệu cần thiết và sẵn sàng mở rộng khi hệ thống phát triển.
